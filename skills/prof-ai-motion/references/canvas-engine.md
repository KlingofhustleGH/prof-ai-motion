# Движок на canvas (`templates/engine.js` + `templates/reel.html`)

Для роликов «плоский 2,5D + вырезки людей + видео + текст» — основной путь. Всё рисуется на одном canvas из `t`,
поэтому работает смаз из подкадров, маски, 3D-кольца текста и вырезки поверх графики. Three.js (`three-d.md`) — когда нужен
настоящий хром, стекло или 3D-эквалайзер из инстансов; его canvas можно положить слоем под/над.

## Подключение
```
cp <skill>/templates/engine.js <skill>/templates/reel.html work/
node <skill>/scripts/fonts.mjs work/assets/fonts "Inter Tight:wght@500;800;900"
node <skill>/scripts/render.mjs stills 1,3,4.5 --dir work --comp reel.html --w 1920 --h 1080
```
Сцены — функции `S(g, t)`, список `[[старт, S], …]` отдаётся в `boot({ canvas, scenes, fonts, cutouts, spectrum, beat0, beat })`.
`beat0` — первая доля в **времени ролика** (время трека минус сдвиг начала), `beat` — длина доли.

## Что есть в движке
| функция | что делает |
|---|---|
| `P(t, at, d)` | шаг «лапами», быстрейшая точка на `at` |
| `walk(t, t0, t1, seed, amp)` / `pong(...)` | новый шаг на каждой доле (случайный / туда-обратно) — «ничего не стоит» |
| `word(g, t, at, s, x, y, size, o)` | слово влетает и дальше прыгает на долях (амплитуды по умолчанию проверены: hx 90, hy 30, масштаб ±12 %, поворот ±0,05) |
| `letters / assemble / burst` | побуквенно: своё смещение/поворот/цвет; сборка из разлёта; взрыв из точки |
| `ring(g, s, cx, cy, R, tilt, ang, size, col, 'back'/'front')` | 3D-кольцо текста; рисуй 'back' до человека, 'front' после |
| `videoInLetters(g, src, draw)` | видео только внутри букв |
| `cutout(g, name, x, y, h, {filter:'brightness(0)'})` | вырезка по высоте; `brightness(0)` — чёрный силуэт-клон |
| `cover(g, src, …)`, `vf(dir, sec, N)` | кадр видео «на весь блок»; путь к кадру по секунде |
| `ball`, `prism`, `extruded`, `shadeFaces` | 3D без WebGL: бумажный шар, призма ▶, выдавленные буквы, любой меш |
| `tunnel`, `confetti`, `cloud`, `portal`, `shutter`, `camera` | фон-туннель, конфетти, плоские облака, круглый портал, шторка-полосы, камера слоя |

## Грабли (уже наступали)
1. **Маска «видео в буквах»**: `destination-in` на каждую букву стирает предыдущие — буквы пустые. Сначала вся маска на отдельный canvas, потом один `destination-in` (так в `videoInLetters`).
2. **Шрифт на кадре 0 — с засечками**: canvas подхватывает начертание при первом использовании. Прогрев каждой гарнитуры в `boot` обязателен.
3. **Картинки не успели раскодироваться** → пустые кадры. В движке проход «сбор»: кадр вызывается вхолостую, собираются все пути, ждём `decode()`, потом рисуем.
4. **Переворот слова в 3D читается зеркально**: для «флипа» бери `|cos|` (слово сжимается в ребро и раскрывается), знак — только для задней половины кольца.
5. **Слова наезжают, когда растёт разрядка**: соседние слова в строке ставь по `tw()` с зазором ≥ 0,5 em и выключай `spread` у заголовков из нескольких слов.
6. **Текст на тёмной одежде вырезки теряется**: кольцо вокруг человека — светлым цветом.
7. **Нырок камерой** целится в конкретную деталь (топ, логотип), не в центр кадра — иначе крупный план случайного места.
8. **Видео 480×854 на весь кадр** — мыло. Такие исходники — в портал/панель ≤ 900 px или под зерно и грейд.
9. Точные перерисовки после мелкой правки: `node <skill>/scripts/patch.mjs 55 67 --dir work --comp comp.html` вместо полного рендера.

## Цифры производительности
19 с × 30 fps × 6 подкадров с фото и видео на 1920×1080 — около 20–30 минут рендера (Chromium без GPU). Пробные кадры — всегда до полного рендера.

# Композиция: кадр = функция времени

## Контракт
- Страница размером ровно с кадр (1080×1920, 1920×1080, 1080×1080).
- `window.renderFrame(t, rt)` — асинхронная, выставляет **всё** состояние кадра по времени `t` и дожидается загрузки нужных картинок. `rt` — реальное время ролика (отличается от `t`, если монтаж подогнан под биты).
- `window.ready` — промис: шрифты загружены, стартовые картинки декодированы.
- Никаких `requestAnimationFrame`, `setTimeout`, `Date.now()`, CSS-анимаций и `transition` — всё считается из `t`. Случайность — только посеянная (`hash(n)`).
- Каждая сцена — блок `if (t >= A && t < B) { show('S5', true); ... }`. В начале кадра все сцены скрываются.

## Видео в кадре
- Разложи клип на кадры: `ffmpeg -i clip.mp4 -q:v 2 work/assets/clip/%03d.jpg`.
- В кадре рисуй на canvas номер кадра по времени; при замедлении смешивай два соседних кадра по дробной части.
- Кадрирование 16:9 → 9:16: сначала сетка кадров с линиями через 10 %, найди где объект, веди окно за ним ключами.
- Резкость: вертикаль из горизонтали — это увеличение в 1,78 раза. Если есть исходник крупнее — бери его.

## Грабли (уже наступали — не повторяй)
1. **Скрывай сцены через `display:none`, а не `visibility:hidden`.** Если ребёнку где-то выставлен `visibility:visible`, он вылезет поверх следующих сцен.
2. **Маска из нескольких надписей.** `globalCompositeOperation='destination-in'` применяется к каждой отрисовке отдельно — вторая надпись сотрёт первую. Нарисуй все надписи на отдельном canvas и наложи его один раз.
3. **Градиентный текст на крутящихся цифрах.** `background-clip:text` на родителе ломается при трансформациях детей — вешай градиент на каждую цифру.
4. **Id в CSS чувствительны к регистру.** `#end` ≠ `#END` — элемент останется без стилей и «пропадёт».
5. **Камера сквозь объекты.** Если камера летит по той же траектории, где висят объекты, экран будет вспыхивать тёмным. Веди камеру по оси, объекты — по спирали вокруг.
6. **Сглаживание времени видео.** Не прогоняй время → номер кадра через ease-in-out: ключевой момент (жест, взгляд) проскочит за доли секунды. Номер кадра считай линейно.
7. **Текст шире кадра.** Каждое длинное слово проверь на стоп-кадре; «ПРОФЕССИОНАЛЬНОГО» в Unbounded 900 на 1080 px — не больше ~60 px.
8. **Пути с пробелами.** Корень сервера бери через `fileURLToPath`, не через `URL.pathname` (там `%20`).
9. **Модули ES.** Если композиция — `<script type="module">`, рендер должен ждать `window.renderFrame` (`waitForFunction`), а не только `window.ready`.
10. **Эмодзи.** В браузере без окна может не быть шрифта эмодзи — не используй их в кадре.

- Смотри каждую сцену и середину каждого перехода.

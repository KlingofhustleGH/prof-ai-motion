# Стили

Каждый стиль — набор токенов. Держи их в `:root` композиции и не смешивай стили внутри одной сцены (кроме сцены «смена стиля» как приёма).

## Ethereal Glass (по умолчанию PROF AI)
- Фон `#050505`, 2–3 мягких светящихся пятна (синий `#7B8CFF`, фиолетовый `#B99BFF`), медленно плывут.
- Текст `#F2F0EA`, акцент — градиент `#A9C8FF → #7B8CFF → #C9A4FF`; горячий акцент `#FFC08A → #FF7A45 → #FF4D6D`.
- Шрифты: заголовки — широкий жирный гротеск (Unbounded 900), текст — Golos Text, метки — моноширинный (PT Mono, разрядка .14em, капс).
- Карточки — «двойная оправа»: внешний тонкий полупрозрачный слой с волосяной обводкой + внутреннее ядро с меньшим радиусом и светлым бликом по верхней кромке.
- Метки-пилюли «01 / 05» перед заголовком сцены.
- Зерно плёнки поверх всего, прозрачность 6–9 %.
- 3D: хром в тёмной студии с полосами света.

## Editorial
- Фон `#F3EEE4`, текст `#1D1A16`, вторичный `#7A7064`.
- Заголовки — журнальный антиква-курсив (DM Serif Display italic), текст — гротеск.
- Фото с лёгкой сепией, белые поля-паспарту, тонкие тени.
- Движение спокойнее: длинные удержания, мягкие наплывы, никакой тряски.

## Brutal
- Фон `#E8E3D8` или `#111`, акцент `#FF3B2F`.
- Жирный гротеск капсом, толстые рамки 8–12 px, жёсткая тень-смещение без размытия.
- Ч/б фото с высоким контрастом.
- Резкие склейки на доле, глитч, штампы.

## Soft
- Фон — пастельный градиент (`#FDE8EF → #E5ECFF`), текст `#4A3D63`.
- Большие скругления (40–60 px), размытые мягкие тени, светлое стекло.
- Пружинные входы с небольшим перелётом, никакой тряски.

## Свой стиль
Попроси 2–4 цвета и референс. Собери токены: фон, текст, акцент, вторичный; шрифт заголовков, шрифт текста, моно; радиус карточек; сила зерна; характер движения (резкий/мягкий).

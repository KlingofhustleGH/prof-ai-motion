# Форматы и безопасные зоны

| Формат | Размер | Где |
|---|---|---|
| 9:16 | 1080×1920 | Reels, Shorts, Stories, TikTok |
| 16:9 | 1920×1080 | YouTube, сайт, презентация |
| 1:1 | 1080×1080 | лента |

30 fps, H.264, `yuv420p`, `-movflags +faststart`, AAC 192k.

## 9:16 для Reels / TikTok / Shorts
Интерфейс площадки закрывает:
- **низ ~22 %** (ниже ~1480 px) — подпись, ник, музыка;
- **правую колонку** ~140 px от ~1000 до ~1700 px по высоте — лайки, комментарии;
- **верх ~200 px** — заголовок ленты.

Текст — только в зоне примерно 64…940 px по ширине и 230…1480 по высоте. Внизу — только изображение без текста.

## 16:9 для YouTube
Держи текст выше нижних ~15 % (полоса плеера и субтитры).

## Из одного монтажа — несколько форматов
Звук и карта времени общие. Пересобирается только вёрстка: копия композиции с другими размерами и раскладкой (в горизонтали — текст слева, медиа справа; видео 16:9 без кадрирования).

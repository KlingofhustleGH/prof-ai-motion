# Правила движения

## Кривые
Встроенные `ease-in-out` и `linear` звучат дёшево. Решатель `bez()` — в шаблонах.

- **Основная кривая для всего, что движется — «мягкие лапы»** `cubic-bezier(.87, 0, .13, 1)`: медленный разгон, сверхбыстрая середина, мягкая посадка. Длительность 0,30–0,50 с, **самая быстрая точка — ровно на доле** (`P(t, beat, d)` в `engine.js`). Цифры и законы — `motion-dna.md`.
- **Мгновенная реакция** (вспышка гаснет, росчерк, отскок) — ease-out `cubic-bezier(.16, 1, .3, 1)` или `(.23, 1, .32, 1)`.
- **Шторки и панели** в DOM-композициях — `cubic-bezier(.32, .72, 0, 1)`.
- `linear` — только бесконечное движение (туннель, линии скорости, бегущая строка, головка таймлайна).
- **ease-in для входа — никогда**.

## Вход и выход
- Ничего не появляется из ничего: старт не меньше `scale(.9)` + прозрачность + `blur(12–14px)`.
- Выход быстрее входа: вход 0,35–0,5 с, выход 0,12–0,16 с.
- Каскад: соседние элементы входят с задержкой 30–80 мс, не больше.
- Размытие (до 20 px) прячет неидеальные стыки переходов.
- Две насыщенные сцены не кроссфейдить друг в друга — будет каша. Либо «старое ушло → новое пришло», либо через тёмный кадр, либо шторкой.

## Ритм
- Все события — на долях. Сильные удары — на сильных долях.
- Текст держится на экране минимум 0,3 с на слово **после** того, как встал целиком — но не стоит: на каждой доле новый шаг (80–250 px / ±10–40 % / 3–25°).
- Крючок — первые 2 секунды. Первый кадр уже должен быть интересным.
- Вспышка на склейке — 1 кадр кремовым/акцентом (85 %) на каждом переходе сцены; длинная вспышка 0,2 с — только на главном ударе.
- Тряска — только на ударах, 0,3 с, затухание.

## Вёрстка
- Крупная типографика, много воздуха. Один главный текст на сцену.
- Двойная оправа для карточек, пилюли-метки над заголовками.
- Зерно плёнки 6–9 % поверх всего — убирает «пластиковость».
- Анимируй только `transform`, `opacity`, `filter`, `clip-path` — это ещё и быстрее рендерится.

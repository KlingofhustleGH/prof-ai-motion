# Вырезки людей и объектов

## macOS — встроенный Vision, локально, без сети и без установки пакетов
```
swiftc -O <skill>/scripts/cutout.swift -o work/cutout        # один раз (нужен Xcode Command Line Tools: xcode-select --install)
work/cutout photo.png work/assets/cut/alice.png largest       # all | largest | smallest — какой объект брать, если их несколько
ffmpeg -i work/assets/cut/alice.png -vf "scale=-1:'min(1500,ih)'" work/assets/cut/alice.png   # ≤ 1500 px по высоте — хватает и рисуется быстро
```
- Результат — PNG с прозрачностью, обрезанный по объекту. Волосы на однотонном фоне (серый циклорамный) режутся чисто.
- **Два человека в кадре**, а нужен задний: сначала `ffmpeg -vf crop=…` на область с ним, потом `cutout … largest`. Иначе Vision берёт главный (передний) объект — так вместо 8 поз танцующей девушки получились 8 одинаковых поз стоящей.
- Кадры из видео: `ffmpeg -ss 2.6 -i clip.mp4 -frames:v 1 f.png` → `cutout`. Для «хронофото» бери 6–8 фаз с шагом ~1 с.
- Лист персонажа (несколько ракурсов на одном изображении): сначала `crop` каждой панели, потом вырезка.

## Проверка — честная
`node <skill>/scripts/cutcheck.mjs work/assets/cut work/cuts.jpg` — каждая вырезка наложена по альфе на розовый.
Не склеивай RGBA через pad/tile в JPEG: прозрачность станет чёрной, и кажется, что вырезка сломана.

## Не macOS
Спроси пользователя. Варианты: вырезка фона в Higgsfield (`extensions.md`), rembg (Python) — только с его согласия, это сторонний пакет.

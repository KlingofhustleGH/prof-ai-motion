# Приёмы для сцен

Каждая сцена — один приём. Не повторяй приём в соседних сценах.

| Приём | Как сделать | Когда |
|---|---|---|
| **Удар слов** | слово появляется со scale 1.6→1 + blur 12→0 за 0,22 с, строго на доле; лёгкая тряска кадра 0,3 с | крючок, финал |
| **3D-хром** | TextGeometry + металл в тёмной студии, прилёт из глубины с вращением, блик-свет проезжает по буквам | крючок, бренд |
| **Штамп** | рамка + текст, scale 1.5→1 за 0,14 с, поворот −4°, удар звука | провокационная фраза |
| **Разлёт на осколки** | объекты (клипы шкалы, плитки) с посеянными скоростями и вращением, гравитация | «ломаем старое» |
| **Печать текста** | символы по времени + мигающий курсор | вопрос, запрос |
| **Шторка-полоса** | светящаяся линия едет поперёк кадра, за ней следующая сцена (`clip-path: inset`) | переход |
| **Трекинг** | уголки-рамка следуют за объектом в видео + живые координаты | «профессиональная анимация» |
| **График плавности** | карточка, где рисуется кривая `cubic-bezier` и по ней бежит точка | объяснить движение |
| **Линии скорости** | штрихи с градиентом едут через кадр, режим `lighter` | езда, динамика |
| **Видео внутри букв** | кадр видео на canvas + маска из текста (`destination-in`), затем пролёт камеры сквозь букву | бренд + видео |
| **3D-эквалайзер** | InstancedMesh-поле столбиков, высота = спектр **финального** звука по кадрам, ряды = история | музыка |
| **Осциллограф** | линия формы волны звука этого кадра, свечение | звук, SFX |
| **Видимые SFX** | каждый звук имеет форму: «вжух» — росчерк, щелчок — круги, удар — ударная волна, глитч — RGB-сдвиг | SFX |
| **Смена стиля на долю** | одна карточка, два слоя стилей, новый открывается шторкой `clip-path` на каждой доле | персонализация |
| **3D-лента плёнки** | кадры-плоскости по спирали, камера летит **по оси** спирали, потом кадры ложатся в сетку-таймлайн | монтаж |
| **Видеостена** | сетка плиток с клипами, плитки выпрыгивают по очереди (каскад 30–80 мс) | работы, кейсы |
| **3D-стена экранов** | скриншоты в перспективе (`rotateX/rotateZ`), колонки едут в разные стороны | сайт, продукт |
| **Счётчики-барабаны** | цифры в колонках 0–9, прокрутка до значения с размытием по скорости | факты (только правдивые) |
| **Инверсия по видео** | огромный текст с `mix-blend-mode: difference` поверх видео | название |
| **Дождь кода** | моноширинные токены падают колонками | «только код» |
| **Частицы в логотип** | точки из пикселей текста, из хаоса летят в позиции | финал |
| **Чат** | пузыри с пружинным входом, «печатает…», ответ с файлом | призыв |
| **HUD** | номер кадра и время в углу — честный, реальный | мета-ролики |

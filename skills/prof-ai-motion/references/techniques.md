# Приёмы для сцен

Каждая сцена — один приём. Не повторяй приём в соседних сценах.

| Приём | Как сделать | Когда |
|---|---|---|
| **Удар слов** | слово появляется со scale 1.6→1 + blur 12→0 за 0,22 с, строго на доле; лёгкая тряска кадра 0,3 с | крючок, финал |
| **3D-хром** | TextGeometry + металл в тёмной студии, прилёт из глубины с вращением, блик-свет проезжает по буквам | крючок, бренд |
| **Штамп** | рамка + текст, scale 1.5→1 за 0,14 с, поворот −4°, удар звука | провокационная фраза |
| **Разлёт на осколки** | объекты (клипы шкалы, плитки) с посеянными скоростями и вращением, гравитация | «ломаем старое» |
| **Печать текста** | символы по времени + мигающий курсор | вопрос, запрос |
| **Шторка-полоса** | светящаяся линия едет поперёк кадра, за ней следующая сцена (`clip-path: inset`) | переход |
| **Трекинг** | уголки-рамка следуют за объектом в видео + живые координаты | «профессиональная анимация» |
| **График плавности** | карточка, где рисуется кривая `cubic-bezier` и по ней бежит точка | объяснить движение |
| **Линии скорости** | штрихи с градиентом едут через кадр, режим `lighter` | езда, динамика |
| **Видео внутри букв** | кадр видео на canvas + маска из текста (`destination-in`), затем пролёт камеры сквозь букву | бренд + видео |
| **3D-эквалайзер** | InstancedMesh-поле столбиков, высота = спектр **финального** звука по кадрам, ряды = история | музыка |
| **Осциллограф** | линия формы волны звука этого кадра, свечение | звук, SFX |
| **Видимые SFX** | каждый звук имеет форму: «вжух» — росчерк, щелчок — круги, удар — ударная волна, глитч — RGB-сдвиг | SFX |
| **Смена стиля на долю** | одна карточка, два слоя стилей, новый открывается шторкой `clip-path` на каждой доле | персонализация |
| **3D-лента плёнки** | кадры-плоскости по спирали, камера летит **по оси** спирали, потом кадры ложатся в сетку-таймлайн | монтаж |
| **Видеостена** | сетка плиток с клипами, плитки выпрыгивают по очереди (каскад 30–80 мс) | работы, кейсы |
| **3D-стена экранов** | скриншоты в перспективе (`rotateX/rotateZ`), колонки едут в разные стороны | сайт, продукт |
| **Счётчики-барабаны** | цифры в колонках 0–9, прокрутка до значения с размытием по скорости | факты (только правдивые) |
| **Инверсия по видео** | огромный текст с `mix-blend-mode: difference` поверх видео | название |
| **Дождь кода** | моноширинные токены падают колонками | «только код» |
| **Частицы в логотип** | точки из пикселей текста, из хаоса летят в позиции | финал |
| **Чат** | пузыри с пружинным входом, «печатает…», ответ с файлом | призыв |
| **HUD** | номер кадра и время в углу — честный, реальный | мета-ролики |

## Приёмы шоурила PROF AI (canvas-движок, `canvas-engine.md`) — проверены, владелец одобрил

| Приём | Как сделать (функция движка) | Когда |
|---|---|---|
| **3D-кольцо текста вокруг человека** | `ring(… 'back')` → вырезка → `ring(… 'front')`; шаг поворота 1,1–1,4 рад «лапами» на каждую долю; светлый текст поверх тёмной одежды | крючок, карточка курса |
| **Клоны-силуэты** | та же вырезка ×2 по бокам, `filter:'brightness(0)'`, выезжают на долю ±460 px и прячутся | крючок, «умножение» |
| **Видео внутри букв → портал** | `videoInLetters` + `assemble`; на сильной доле из буквы «o» раскрывается круглый портал на весь кадр | выход модели, бренд |
| **Чертёж / HUD поверх видео** | выноски линиями «лапами» к деталям, подписи, бегущий тайм-код | техника, продукт |
| **Шторка-полосы** | `shutter()` — 12 полос разъезжаются в разные стороны за 0,16 с | переход |
| **Кручение по дуге → строка** | буквы стоят по краю портала/окружности, на долю разворачиваются в прямую строку | «новая …» |
| **Схлоп → взрыв** | `burst()` — слово из точки 0,02 → 1 | главное слово сцены |
| **Человек прислонился к слову** | огромное слово как стена + вырезка, плечом в край слова; параллакс ×0,35/×0,8/×1,25 | «никакой … работы» |
| **Слово сминается в 3D-шар** | буквы сходятся в точку (0,2 с) → `ball()` падает и отскакивает | «ломаем ручное» |
| **Туннель из ассетов** | `tunnel()` + вырезки/кадры вылетают из центра мимо камеры по одной на полдоли | «это сделал Claude» |
| **Персонаж на эквалайзере** | столбики из спектра финального микса = земля; вырезка скачет по ним (подскок каждые 0,25 с) | звук и музыка |
| **Буквы-эквалайзер** | каждая буква слова подпрыгивает по своей полосе спектра | «музыка» |
| **Смена образа на долю** | 3 вырезки одного человека в разных образах сменяют друг друга рывком со смазом; фон чёрный/акцент/кремовый | «стиль» |
| **Слово-флип со сменой шрифта** | масштаб по X = `|cos|` каждые 0,25 с, шрифт меняется, когда слово ребром | «шрифты» |
| **Три панели каскадом** | 3 вертикальных окна с разными видео, склейка по очереди на каждой четверти доли + вспышка внутри окна | «склейки» |
| **Слово режут ножницами** | верх и низ слова клипами, каждые 0,25 с половинки разъезжаются на 40 px и срастаются | «склейки» |
| **Хронофото** | 6–8 фаз движения человека (вырезки из видео) по дуге, по одной на 1/8 доли | «от а до я», движение |
| **Выдавленные буквы-небоскрёбы** | `extruded()` вырастают из земли на долю | крупные буквы |
| **Сообщение уносит персонаж** | печать в поле ввода → отправка → пузырь «садится» на вырезку, та проносится через кадр | призыв |

# Монтаж под биты чужого трека

Идея: композиция написана в своих долях (120 BPM, доля 0,5 с). Каждую долю ролика привязываем к доле трека. Картинка, SFX и визуализация звука едут по одной карте.

## 1. Биты
```
ffmpeg -i track.mp3 -ac 1 -ar 22050 -f f32le track.raw
node scripts/beats.mjs track.raw
```
Скрипт считает поток атак (spectral flux), темп автокорреляцией, фазу по низкочастотным атакам (бочка) и **проверяет себя**: средняя атака на долях против середины между долями. Если «между» сильнее — фаза сдвинута на полдоли, скрипт это покажет.
Затем подгонка по бочкам с отбрасыванием выбросов → `kickgrid.json` (`a` — фаза, `P` — период бочки).

Темп вроде 82/164 — это одно и то же в половинном/двойном счёте. Бочка обычно на половинном.

## 2. Вход бита
Посмотри профиль энергии вокруг конца вступления (скрипт печатает) — там, где низкие частоты резко растут, входит бит. Самый сильный визуальный момент (приземление логотипа, дроп сцены) ставь туда.

## 3. Карта времени
`scripts/warp.mjs` — участки «доли ролика → доли трека»:
- крючок — по бочке (медленнее, слова успевают ударить);
- основная часть — по доле (плотнее);
- призыв и финал — снова по бочке (успевают прочитать).
Выход: `warp.json` (`Ts` — с какого места трека начать, участки, число кадров).

## 4. Рендер с картой
`node scripts/render.mjs wfull` — для каждого реального кадра считает время композиции по карте и передаёт в `renderFrame(t, rt)`. Номер кадра в HUD, эквалайзер и осциллограф берут `rt` — реальное время, иначе разойдутся со звуком.

## 5. SFX
`scripts/sfx-lib.mjs` + `at(tau)` из карты: `boom(at(2.0))` ударит ровно в долю трека.

## Ограничения (говори пользователю)
- Трек с плавающим темпом или сменой темпа — синхронизация по участкам, дольше.
- Ты не слышишь — попадание проверено данными (атаки на долях), итог на слух оценивает человек.

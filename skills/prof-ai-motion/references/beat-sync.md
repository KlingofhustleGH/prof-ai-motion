# Монтаж под биты чужого трека

Идея: композиция написана в своих долях (120 BPM, доля 0,5 с). Каждую долю ролика привязываем к доле трека. Картинка, SFX и визуализация звука едут по одной карте.

## 1. Биты
```
node scripts/beats.mjs track.mp3        # любой аудио/видеофайл; или track.raw (f32le mono 22050 Гц)
```
Скрипт считает поток атак (spectral flux) и темп автокорреляцией, потом **уточняет период ±1,5 %** и **складывает энергию низа
по сетке 1/2/3/4 долей** — фаза с лучшим контрастом «на доле / между долями» и есть сетка. Печатает, каждые сколько долей
сильный удар (у трека шоурила — каждые 2–3), и список самых сильных ударов низа — **сверь их с сеткой глазами**.
Выход `kickgrid.json`: `a` (фаза), `P` (2 доли), `beat`, `beatBpm`, `accentEvery`, `accentPhase`, `entry`.

⚠ WAV/MP3, прочитанный как raw, даёт мусор («на долях 1.7e36») — теперь скрипт декодирует сам и отказывается от явно не-звука.

## 1а. Плотный микс — фазу выбирает человек
На сжатых треках с непрерывным сабом (LRA < 3 LU, `ebur128`) разные методы расходятся по фазе до ~0,1 с — у трека шоурила
ручная подгонка дала 0,332 с, свёртка низа 0,436 с, полнополосные атаки 0,42–0,44 с. Ты не слышишь — не выбирай сам:
```
node scripts/clicktest.mjs track.mp3 --beat 0.5 --phases 0.332,0.436 --from 4 --dur 8 --out work/clicktest
```
Отдай пользователю `clicktest-A.wav` / `-B.wav`: где щелчок совпал с бочкой — ту фазу и бери. До ответа пиши в отчёте «фаза не подтверждена на слух».

## 2. Вход бита
Посмотри профиль энергии вокруг конца вступления (скрипт печатает) — там, где низкие частоты резко растут, входит бит. Самый сильный визуальный момент (приземление логотипа, дроп сцены) ставь туда.

## 3. Карта времени
`scripts/warp.mjs` — участки «доли ролика → доли трека»:
- крючок — по бочке (медленнее, слова успевают ударить);
- основная часть — по доле (плотнее);
- призыв и финал — снова по бочке (успевают прочитать).
Выход: `warp.json` (`Ts` — с какого места трека начать, участки, число кадров).

## 4. Рендер с картой
`node scripts/render.mjs wfull` — для каждого реального кадра считает время композиции по карте и передаёт в `renderFrame(t, rt)`. Номер кадра в HUD, эквалайзер и осциллограф берут `rt` — реальное время, иначе разойдутся со звуком.

## 5. SFX
`scripts/sfx-lib.mjs` + `at(tau)` из карты: `boom(at(2.0))` ударит ровно в долю трека.

## Ограничения (говори пользователю)
- Трек с плавающим темпом или сменой темпа — синхронизация по участкам, дольше.
- Ты не слышишь — попадание проверено данными (атаки на долях), итог на слух оценивает человек.
